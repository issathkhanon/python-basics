# Python Basics

Four lessons for someone learning Python from the start. Open them in order and run each code cell with Shift+Enter.

1. [How Python reads your code](learn_python_basics/01_learn_python_basics.ipynb) — names, indentation, lines, and types
2. [Variables, types, and input](learn_python_basics/02_learn_variables_and_data_types.ipynb) — storing values, converting types, and reading the keyboard
3. [Operators](learn_python_basics/03_learn_operators.ipynb) — arithmetic, comparison, and logic
4. [Conditionals and loops](learn_python_basics/04_learn_conditionals_and_loops.ipynb) — decisions, repetition, and stopping a loop early
